# yii-app

A small Yii 2 application for the engine's tests, laid out like Yii's basic application
template: a configuration with components, a module and parameters, controllers, Active
Record models with relations, a migration making their tables, a form model, views with
a layout, a widget, a mail view and a message file.

Nothing here is Yii's. `lib/` stands in for it: the names of the classes and methods the
application uses, written for this fixture. `composer.json` names `yiisoft/yii2`, which is
what makes the project a Yii one.
