# symfony-app

A small Symfony application for the engine's and the VS Code extension's tests: a
controller, a service, routes and services in YAML, Twig templates and a translation
catalogue.

Nothing here is Symfony's. `lib/` stands in for it: the names of the classes and methods
the application uses, written for this fixture. `composer.json` names
`symfony/framework-bundle`, which is what makes the project a Symfony one.
